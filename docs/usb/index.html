Install from this computer over USB

For Android TV boxes whose USB port can talk to a computer, such as Chromecast with Google TV and Nvidia Shield TV: Chrome or Edge installs Sofa Tube over a cable. No Downloader, no "Install unknown apps" switch.

New in 0.9.6. Tested with a simulated USB box and the Android TV emulator, not yet on a real Chromecast or Shield. If it does not work, use Sofa Tube Setup or the Downloader way, and tell us what happened.

Boxes and cable

Chromecast with Google TV (4K and HD)

Its only USB-C port (the power port) to the computer, with a cable that carries data (USB-A to USB-C, or USB-C to USB-C). The box runs on the computer's power meanwhile: if it restarts or does not start, use another USB port of the computer or a powered USB hub.

Nvidia Shield TV Pro (2019) and Shield TV (2017)

A USB-A to USB-A cable from the computer to one of the box's USB ports (if the box is not seen, try the other port). The box stays on its own power. The tube-shaped Shield TV (2019) has no USB port.

TV sets and most other boxes

The USB ports of TV sets (TCL, Sony, Hisense and others) and of most Fire TV devices cannot talk to a computer this way. Use Sofa Tube Setup or the install steps.

Steps

  1. Turn on USB debugging on the box (once).
    • Google TV and Chromecast: Settings → System → About. Move to Android TV OS build and press OK seven times, until "You are now a developer". Then Settings → System → Developer options → USB debugging: on.
    • Shield: Settings → Device Preferences → About → Build seven times, then Device Preferences → Developer options → USB debugging: on.
  2. Connect the cable as above. Close other programs on this computer that use Android devices (adb, Android Studio, scrcpy).
  3. Get the Sofa Tube file.

    Download Sofa Tube (.apk)

  4. Connect the box and install. The browser opens a list: choose the box, then Connect.

  5. On the TV: it asks "Allow USB debugging?". Move to Allow with the remote and press OK. Tick "Always allow from this computer" to skip the question next time.
  6. After "Done", Sofa Tube opens on the TV. You can then turn USB debugging off again in Developer options.

Safety and privacy

  • Everything happens in this browser: no server between the computer and the box.
  • Before installing, the page checks the release list's (version.json) signature with Sofa Tube's key, and the file's size and checksum (sha256).
  • The browser keeps a key for this computer so the box knows it (as adb does). To remove it: Developer options → Revoke USB debugging authorizations.
  • The page uses Tango (ya-webadb), MIT licence, copied onto this site.

Works in Google Chrome and Microsoft Edge on Windows, Mac, Linux and Chromebook. Not in Firefox or Safari, and not on an iPhone (none of them has WebUSB).
