Sofa Tube Setup

Installs Sofa Tube on your TV from a computer or an Android phone. You never type on the TV: codes, links and logins are typed on the computer or phone, and Setup sends them to the TV with the TV maker's own remote protocol.

Version 0.9.6 · for Android TV, Google TV, LG and Samsung. The TV and the computer (or phone) on the same Wi-Fi.

Android phone Your device

Sofa Tube Setup for the phone: no computer needed.

Download the phone app (.apk)

The first time, Android asks to allow your browser to install apps: tap Settings, turn on Allow from this source, go back and tap Install.

Windows or Mac computer Your deviceYour device

One file, nothing to install: open it and the Setup page opens in your browser by itself.

Windows 10 and 11 (.exe, about 92 MB) Mac (.zip)

Keep the Setup window open until Sofa Tube runs on the TV. The Mac version is not yet tested on a real Mac.

Only an iPhone or iPad? Your device

Apple's App Store allows no app that installs apps on a TV. Use a Windows or Mac computer on the same Wi-Fi once, or an Android phone. After the install, the phone remote works on the iPhone as usual.

Send this page's link to the computer: sofatube.github.io/setup/

Android TV box with a USB port: install from this computer

Chromecast with Google TV or Nvidia Shield TV, a USB cable and Chrome or Edge: the browser installs Sofa Tube over the cable. Useful when Downloader does not work. New, not yet tried on a real box.

Install over USB

The first time you open it

The Setup files are not signed yet (a signature would show a person's name; Sofa Tube publishes only as Sofa Tube). So the system warns once:

  • Windows: the browser may say the file "isn't commonly downloaded": choose Keep. Then Microsoft Defender SmartScreen says "Windows protected your PC": click More info, then Run anyway. If Windows Firewall asks, allow private networks.
  • Mac: unzip the file and double-click Sofa Tube Setup.command. If the Mac says it cannot check it: close the message, open System Settings → Privacy & Security, scroll to Security, click Open Anyway and confirm with your Mac password. A Terminal window opens; the first time, Setup downloads Node.js from nodejs.org (about 50 MB) if the Mac has none.
  • Android: allow the browser to install apps once (above).

What Setup asks on each TV

Android TV · Google TV

  1. Pick the TV in Setup. The TV shows a 6-character code: type it in Setup (not on the TV).
  2. Setup opens the Downloader app, types the link and downloads Sofa Tube. If Downloader is not installed, install it from the TV's app store (the voice search button finds it without typing).
  3. On Android's install screen: move to INSTALL with an arrow button and press OK. Only the TV's own remote can do this press. The first time, the TV may ask to allow Downloader to install apps.
  4. Setup opens Sofa Tube and shows the QR code for the phone remote.

LG TV (webOS)

  1. Press YES on the TV when it asks to allow Sofa Tube Setup (once).
  2. Setup opens the Developer Mode app (or its LG Content Store page, to install it). Sign in with your free LG developer account (made in a browser at webostv.developer.lge.com): select the field on the TV with OK and type in Setup.
  3. Turn on Dev Mode Status (the TV restarts), then Key Server.
  4. Type the Passphrase the TV shows in Setup: Setup installs Sofa Tube and Sofa Tube Phone itself and opens Sofa Tube.

The Developer Mode session runs out: how to keep it.

Samsung TV (Tizen)

  1. Choose Allow on the TV when it asks about Sofa Tube Setup (once).
  2. Setup opens Apps and presses 1 2 3 4 5. In the Developer mode window switch it on, select the Host PC IP field with OK (Setup types the computer's address), press OK and restart the TV (hold the Power button).
  3. Setup installs Sofa Tube, repeats the step above with 127.0.0.1 (Sofa Tube needs it to start) and opens it.
  4. Samsung TVs from 2023 on (Tizen 7 and newer) take only an app signed for them with the owner's Samsung certificate. Setup prepares Developer mode, then points to the Apps2Samsung route.

Setup's Samsung route is new and not yet tested on a real Samsung TV.

Privacy

  • Setup runs on your own device; its page is only on that device (127.0.0.1). The pairing with the TV stays on that device.
  • What you type for the TV (such as the LG developer account) goes straight to the TV and is not saved.
  • The Sofa Tube files come from the release page; Setup checks the release list's signature and each file's checksum before anything reaches the TV.
