Install

Pick your TV. Same steps as in the tester guide.

  • Android TV · Google TV · Fire TV
  • LG TV
  • Samsung TV

Android TV · Google TV · Fire TV

Status: tried on a Google TV emulator, and test builds of it on one real Android TV (TCL). Fire TV is untested. If it does not install or open at all, that is an important result: tell us.

You need

  • An Android TV, Google TV or Fire TV device (TV, stick or box) with internet. No computer.
  • About 200 MB free space (the app is 95 MB). It runs next to the normal YouTube app.
  • If TizenTube Cobalt is installed, uninstall it first (both use the same phone-link port).

Easiest: the Downloader app (no computer)

  1. On the TV, open the app store (Google Play, or the Appstore on Fire TV), search Downloader (by AFTVnews, orange icon) and install it.
  2. Allow Downloader to install unknown apps:
    • Android TV / Google TV: Settings → Apps → Security & restrictions → Unknown sources → Downloader on. Not there? Settings → System → About → press Android TV OS build 7 times, then try again. (Names differ a little by brand.)
    • Fire TV: Settings → My Fire TV → Developer options → Install unknown apps → Downloader on. No Developer options? Settings → My Fire TV → About → press the device name 7 times.
  3. Open Downloader (allow its storage request), select the address box and type: sofatube.github.io/tv then press Go.
  4. When the download ends, choose Install, then Open. Downloader then offers to delete the downloaded file: Delete saves space.

Fallback: USB stick (needs a computer)

Download the .apk from sofatube.github.io/tv, copy it to a USB stick, open it on the TV with a file manager app, allow that app to install unknown apps, then Install, Open.

Good to know

  • The first start may reload YouTube once; that is normal. Most Android remotes have no colour buttons: use ★ Sofa Tube in YouTube's sidebar or the ★ button in the player bar.
  • Phone settings need no extra app here: Settings → Phone remote (the first page).
  • Updates: install the new .apk over this one the same way; settings stay.

LG TV (webOS)

First: uninstall the official YouTube app from the TV. Sofa Tube uses the same app ID (youtube.leanback.v4), so both cannot be installed together. New: installing from a phone has not been tried by us yet; tell us how it went.

You need

An LG webOS TV and an Android phone on the same Wi-Fi (or a computer). A free LG Developer account and LG's Developer Mode app. No rooting, no Homebrew Channel.

Easiest: with an Android phone

  1. On the phone, create an LG Developer account at webostv.developer.lge.com.
  2. On the TV, install Developer Mode from the LG Content Store, open it and sign in with that account.
  3. Turn on Dev Mode Status (the TV restarts), open the app again and turn on Key Server. Write down the IP address and the passphrase.
  4. On the phone, install webOS Dev Manager: github.com/webosbrew/dev-manager-desktop → Releases → the file ending universal.apk. Allow your browser to install unknown apps when asked.
  5. In webOS Dev Manager, add the TV with that IP and passphrase.
  6. In the phone's browser, open sofatube.github.io/lg and sofatube.github.io/lg-phone: both files download.
  7. In webOS Dev Manager, install the main app .ipk, then the Phone app .ipk, from the phone's Downloads.
  8. On the TV, open Sofa Tube. The first-time setup asks for language, PIN and kid mode. Green opens the settings.

Fallback: with a computer

Same steps, with webOS Dev Manager for Windows, Mac or Linux (same page) and the two .ipk files from the links above.

Good to know

  • Developer Mode sessions expire, and then the apps you installed stop opening. Open the Developer Mode app now and then and extend the session.
  • Sofa Tube Phone is a second app: open it to change settings from your phone (QR code). Screen off also needs it opened once after the TV starts.
  • Updating later: install the new .ipk the same way; your settings stay.

Samsung TV (Tizen)

Status: Sofa Tube is its own app on the TV (an icon in Apps). Installing it was tried on Samsung's TV emulator; it has not been tried on a real Samsung TV yet, so you are one of the first: tell us how it went.

You need

  • A Samsung TV from 2018 or newer (Tizen 4.0 or newer), and an Android phone on the same Wi-Fi. No Android phone (iPhone)? Use a Windows or Mac computer instead (below).
  • A free Samsung account: Apps2Samsung on a phone asks you to sign in at the first install, for any TV (on a computer only for TVs with Tizen 7 or newer, most TVs from 2023 on). It makes your own signing certificate from it and keeps it, so you sign in once.

With an Android phone (no computer): 6 steps

  1. TV: open Apps, type 1 2 3 4 5 (number keys, or the remote's 123 / colour button for on-screen numbers). Set Developer mode to On, type the phone's IP address in Host PC IP, press OK, then restart the TV: hold the remote's Power button until it turns off and on again. (The phone's IP: Settings → Wi-Fi → your network → IP address.)
  2. Phone: install Apps2Samsung: github.com/Apps2Samsung/Apps2Samsung/releases → the file ending -android.apk. Chrome warns "File might be harmful": tap Download anyway, then Open. If the phone says it isn't allowed to install unknown apps from this source: Settings → turn on Allow from this source → back → Install. If Apps2Samsung shows "Update Available" when it opens, either answer is fine (Later is enough).
  3. Phone: open sofatube.github.io/samsung: the Sofa Tube file (SofaTube-…-Samsung.wgt) downloads.
  4. Apps2Samsung: tap the App box and scroll to the end of the list: 📁 Custom WGT / TPK…, then pick the Sofa Tube file (SofaTube-…-Samsung.wgt); it says "Custom package ready". Select TV shows your TV's IP (tap ⟳ if it is missing). Tap Download & Install. The first time a Samsung Account page opens: sign in (or Sign in with Google). The first install can take a few minutes. Done when it shows "… has been successfully installed!" (tap Close) and "Installed … Open the TV's Apps list to launch it."
  5. TV: Apps → 1 2 3 4 5 again, Host PC IP = 127.0.0.1, OK, restart the TV (hold Power). Arabic TV menus show the address reversed: type 1.0.0.127.
  6. TV: open Sofa Tube from Apps. If it shows "One last step on the TV", do what it says (it shows the Host PC IP it found).
No Android phone? With a Windows or Mac computer (6 steps)
  1. TV: step 1 above, with the computer's IP address in Host PC IP (Windows: Settings → Network & internet → your connection → IPv4 address; Mac: System Settings → Wi-Fi → Details → IP address).
  2. Computer: install Apps2Samsung from its releases: Windows -win-x64.msi, Mac -macos-arm64.dmg (Apple chip) or -macos-x64.dmg (Intel).
  3. Computer: download Sofa Tube from sofatube.github.io/samsung.
  4. Apps2Samsung: Select TV (or type its IP), choose Custom WGT / TPK, pick the Sofa Tube file, Download & Install. Sign in to Samsung if asked (once).
  5. TV: Host PC IP = 127.0.0.1 (Arabic menus: 1.0.0.127), restart the TV.
  6. TV: open Sofa Tube from Apps.

Also works: TizenBrew Installer on the computer → open http://localhost:8091/ui/dist/index.html → TV IP → Install from GitHub → sofatube/sofatube.github.io. English only; use "Install from GitHub" rather than "Select file to install" (the file option forgets your Samsung certificate after one install).

Already use TizenBrew? The TizenBrew module

In TizenBrew, press Green, add an NPM module: sofatube. It updates itself; open Sofa Tube from TizenBrew (TizenBrew → Settings → Autolaunch can open it straight away). Installing TizenBrew itself needs a computer and TizenBrew Installer.

If something goes wrong
  • "TV detected, but Developer Mode is off": do step 1 again and restart the TV.
  • "Developer Mode IP doesn't match": Host PC IP must be the IP of this phone or computer; type it again, restart the TV.
  • "IP is in reversed order on the TV" (Arabic menus): type the address reversed, e.g. 192.168.1.5 → 5.1.168.192.
  • "debug port isn't responding … power-cycle": unplug the TV for 30 seconds, plug it in, tap ⟳ (Rescan).
  • "Could not read a valid TV DUID": tap Download & Install again; if it repeats, restart the TV.
  • "Install failed: A task was canceled.": the TV dropped the connection during the install. Restart the TV (hold Power), tap ⟳, pick the file again, Download & Install (no second sign-in).
  • "Sign-in cancelled.": the Samsung page was closed before signing in; tap Download & Install again and sign in.
  • "already installed with a different signing certificate" or "already installed and your TV doesn't allow replacing": an older Sofa Tube with another certificate is on the TV. On the TV, Apps → Sofa Tube → hold OK → Delete, then install again (its settings are lost; save a settings code first).
  • TV not found ("No TVs found"): same Wi-Fi for TV and phone/computer; turn a VPN off; or tap the Select TV box and type the TV's IP (TV: Settings → General → Network → Network Status → IP Settings).
  • Sofa Tube opens "One last step on the TV": step 5 is missing (Host PC IP must be 127.0.0.1) or the TV was not restarted.

Good to know

  • Voice search: YouTube on Samsung has no microphone here. Search by voice from your phone: phone page → Search → 🎤.
  • Updates: Sofa Tube → Settings → Backup and about → Check for updates. When it can, it updates on the TV itself; otherwise it shows the steps (install the new file the same way; settings stay).
  • Developer mode must stay On with Host PC IP 127.0.0.1: Sofa Tube needs it every time it opens YouTube.
